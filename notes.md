## RoadRaven v0.5.0 — first public alpha

**Your plans, visualized and alive.** A local-first desktop app that turns a
plain-JSON roadmap into a live tree — nodes update themselves as your tools,
scripts, and agents report progress. No cloud, no account.

### Highlights
- **Visual tree editor** — build and edit hierarchical roadmaps, keyboard-first, with markdown side panels. Your data is a JSON file you own.
- **Live status updates** — any local process can push node status over a WebSocket Event API and watch nodes change state in real time.
- **Themeable UI** — three built-in themes plus per-file overrides.
- **AI integration** — agents can read, create, and update roadmap nodes via the bundled MCP server.

### Install
- **Windows:** download the `stable-win-x64-RoadRaven-Setup.zip`, unzip, run the installer.
- **Linux:** download the `stable-linux-x64-RoadRaven-Setup.tar.gz`, extract, and run.
